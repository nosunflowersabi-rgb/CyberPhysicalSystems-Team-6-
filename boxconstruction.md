# Mirror Box Assembly Guide

The mirror box forms the main body of the work and creates the infinity effect.

## Materials

- Five 600 × 400 mm x 3mm sheets of Hobarts extruded mirror acrylic
- A mallet with a soft striking surface
- Hinges for attaching the front panel
- File (optional) 
- Two-way mirror for the eye hole (optional)

## Prepare the Files

1. Download the mirror box files
2. Laser-cut the **black and blue lines**
3. Treat the **red text as informational**; it provides assembly guidance and is not part of the cut
4. Cut the mirror acrylic on its **non-reflective side** to ensure proper laser operation - keep this in mind when adding holes for mechanisms! 


## Assembly

1. Assemble the back, top, bottom, and side panels using the finger joints
2. If the fit is too tight, use a file to make the holes bigger. 
3. Use a mallet and gentle tapping to join the panels. Do this carefully, as the mirror acrylic may crack. 
4. Attach the front panel with a hinge. This keeps the inside of the box accessible for assembly and adjustments.

## Optional Eye-Hole Cover

Cover the eye hole with two-way mirror acrylic. This prevents the viewer from seeing their own eyes reflected in the mirror box.

The files were created using the (https://www.festi.info/boxes.py/) box generator and edited to include holes for the mechanisms. To add or remove mechanisms, edit the PDF before laser cutting.
